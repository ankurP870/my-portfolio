Vehicle Rental System

Vehicle Rental System is a web-based application designed to make vehicle rental management simple and convenient. Users can explore available vehicles and manage their rental requirements through the application.

Project Features

  • User-friendly vehicle browsing interface
  • Vehicle details and rental information
  • Responsive web design
  • Frontend developed using React
  • Node.js and Express.js backend
  • MongoDB database integration
  • REST API based application
  • Git and GitHub version control
